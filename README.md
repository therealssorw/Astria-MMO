# Astria-MMO

A Voxel MMO RPG, trying to replace Hypixel (kinda...)

FILE STRUCTURE:
assets: place where the visual for the game goes (models, textures, UI, images, icons, etc)
core: for Singleton files (GameManager, SignalBus, etc) and for resources/datas (example: PlayerStats)
game: collection of scenes (world, player, enemies, etc)
others: plugins, addons, whatever outside the core godot features
